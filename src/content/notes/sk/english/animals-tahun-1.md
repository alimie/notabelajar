## Animals / Haiwan

Haiwan peliharaan (pets):

| English | Bahasa Melayu |
|---------|----------------|
| Cat | Kucing |
| Dog | Anjing |
| Fish | Ikan |
| Bird | Burung |
| Rabbit | Arnab |
| Hamster | Hamster |

Haiwan liar (wild animals):

| English | Bahasa Melayu |
|---------|----------------|
| Lion | Singa |
| Tiger | Harimau |
| Elephant | Gajah |
| Monkey | Monyet |
| Snake | Ular |
| Crocodile | Buaya |

## Ayat Mudah

- I have a **cat**. — Saya ada seekor kucing.
- The **dog** is big. — Anjing itu besar.
- I like **rabbits**. — Saya suka arnab.

> **Tips:** Cuba sebut nama haiwan dalam English setiap kali nampak haiwan!
