## Anggota Badan

Tubuh badan kita terdiri daripada beberapa bahagian utama:

| Bahagian | Contoh Anggota |
|----------|----------------|
| Kepala | rambut, mata, hidung, mulut, telinga |
| Badan | bahu, dada, perut, belakang |
| Anggota atas | tangan, siku, lengan, jari |
| Anggota bawah | kaki, lutut, peha, betis, tapak kaki |

### Kegunaan Anggota Badan

- **Mata** — untuk melihat
- **Telinga** — untuk mendengar
- **Hidung** — untuk mencium bau
- **Mulut** — untuk makan, bercakap
- **Tangan** — untuk memegang, menulis, melukis
- **Kaki** — untuk berjalan, berlari, melompat

## Lima Deria

| Deria | Anggota | Fungsi |
|-------|---------|--------|
| Penglihatan | Mata | Melihat warna, bentuk, saiz |
| Pendengaran | Telinga | Mendengar bunyi |
| Bau | Hidung | Mencium bau |
| Rasa | Lidah | merasa manis, masam, masin, pahit |
| Sentuhan | Kulit | merasakan kasar, halus, panas, sejuk |

> **Fakta seronok:** Lidah kita mempunyai lebih kurang 10,000 tunas rasa!

4. Apakah yang kita guna untuk memegang pensel?
